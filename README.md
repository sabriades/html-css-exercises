# HTML & CSS Exercises

Small collection of basic **HTML** and **CSS** exercises created in 2024 while learning the fundamentals of front-end development. The project was paused due to university commitments.
The repository includes simple practice challenges exploring essential concepts such as styling, buttons, hover effects and layout.

---

## Tech Stack
- **Structure:** HTML
- **Styling:** CSS

---

## Main Features
- Basic HTML structure exercises
- Simple CSS styling and hover effects
- Button and opacity practice
- Small layout and component challenges

*Project created for learning and portfolio purposes.*
